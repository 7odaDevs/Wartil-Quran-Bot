## 📖 نبذة

**ورتل** بوت ديسكورد بيشغّل **القرآن الكريم كامل (114 سورة)** في الروم الصوتي بأصوات مجموعة من أشهر القرّاء، ومعاه **مواقيت الصلاة والأذان** و**الأذكار** و**تنبيهات** إيمانية بشكل صور جميلة.

> ﴿ وَرَتِّلِ الْقُرْآنَ تَرْتِيلًا ﴾

## ✨ المميزات

- 🎙️ **إذاعة قرآن كاملة** بـ 14 قارئ، والتشغيل مستمر والبوت بينتقل للسورة اللي بعدها أوتوماتيك.
- 🎛️ **لوحة تحكم** بقايمة اختيار القارئ والسورة وأزرار (تخطي / إيقاف مؤقت / استكمال / إعادة القرآن).
- 🔁 **إعادة اتصال تلقائية** بالروم الصوتي لو الاتصال وقع أو البوت اتعمله restart.
- 🕌 **مواقيت الصلاة** بصورة جاهزة وإشعار أذان في وقته، مع إمكانية منشن رتبة معيّنة.
- 📿 **أذكار** بتتبعت كل فترة على شكل صور.
- 🔔 **تنبيهات إيمانية** في أوقات عشوائية.
- 🌍 **يشتغل على أكتر من سيرفر** في نفس الوقت، وكل سيرفر ليه إعداداته.
- 📊 **إحصائيات** بسيطة (أكتر قارئ اتسمع، عدد السور المشغّلة...).
- ➕ **سهل التخصيص:** إضافة قارئ جديد = ملف JSON واحد.

## 🚀 تشغيل سريع

```bash
# 1) نزّل المشروع
git clone https://github.com/<اسمك>/<اسم-المشروع>.git
cd <اسم-المشروع>

# 2) نزّل المكتبات
npm install

# 3) جهّز ملف الإعدادات (وعدّل فيه التوكن و CLIENT_ID)
cp .env.example .env

# 4) شغّل البوت
npm start
```

وبعدها في ديسكورد اكتب `/setup` واختار الرومات. ✅

> المتطلبات: **Node.js 18 أو أحدث**.

## ⚙️ الإعدادات (`.env`)

| المتغير | مطلوب؟ | الوصف |
|---|---|---|
| `BOT_TOKEN` | ✅ | توكن البوت |
| `CLIENT_ID` | موصى به | الـ Application ID (لرابط الدعوة) |
| `ALLOWED_GUILD_ID` | ❌ | تقييد البوت على سيرفر واحد |
| `JOIN_LOG_CHANNEL_ID` | ❌ | روم لوج دخول السيرفرات |
| `BOT_LOGO_URL` | ❌ | لوجو لوحة التحكم |
| `PANEL_BANNER_URL` | ❌ | صورة كبيرة أسفل لوحة التحكم |
| `SUPPORT_SERVER_URL` | ❌ | لينك سيرفر الدعم في حالة البوت |

## 💬 الأوامر

| الأمر | الوصف |
|---|---|
| `/setup` | تجهيز البوت في السيرفر (للأدمن) |
| `/country` | اختيار الدولة لمواقيت الصلاة (للأدمن) |
| `/prayer status` | تشغيل/إيقاف تنبيهات الأذان (للأدمن) |
| `/link-invite` | رابط دعوة البوت |

## 🗂️ هيكل المشروع

```
.
├── index.js                 # نقطة البداية
├── config/                  # الإعدادات والثوابت
├── handlers/                # الأوامر والأزرار والقوايم وأحداث الصوت
│   └── commands/            # أوامر السلاش (/setup /country ...)
├── services/                # الخدمات: القرآن، الصوت، الصلاة، الأذكار، التنبيهات
├── models/                  # حفظ إعدادات وبيانات السيرفرات
├── utils/                   # دوال مساعدة ولوحة التحكم واللوج
├── data/
│   ├── reciters/            # ملف JSON لكل قارئ  ← هنا بتضيف وتحذف الشيوخ
│   ├── quran_data.json      # بيانات السور
│   └── azkar.json           # الأذكار
├── assets/
│   ├── fonts/               # الخطوط العربية
│   └── templates/           # قوالب الصور (مواقيت/أذكار/تنبيهات)
├── docs/                    # الشروحات
├── .env.example             # مثال لملف الإعدادات
└── package.json
```

> بيانات السيرفرات (`data/guilds` وملفات الإعدادات) بتتعمل أوتوماتيك وانت شغال، وبتتتجاهل في Git.

## 🔒 الأمان

- **متنشرش** ملف `.env` ولا التوكن أبداً. لو اتسرّب اعمله **Reset Token** من Developer Portal فوراً.
- الملف `.gitignore` متظبط يمنع رفع `.env` وبيانات السيرفرات.
