# 📦 المتطلبات اللازمة للتشغيل

## 1) على جهازك / السيرفر

| المطلوب | التفاصيل |
|---|---|
| **Node.js** | نسخة **18 أو أحدث** (يفضل 20 LTS) — حمّله من https://nodejs.org |
| **npm** | بينزل مع Node.js أوتوماتيك |
| **إنترنت** | البوت بيجيب الصوت من الإنترنت ومواقيت الصلاة من API |
| **رامات** | 512MB كفاية للسيرفرات الصغيرة، ويفضل 1GB لو شغال على سيرفرات كتير |
| **حساب ديسكورد** | عشان تعمل بوت من Developer Portal |

> ✅ **مش محتاج** تنزّل FFmpeg بنفسك، لأنه بيتنزل مع المكتبات (`ffmpeg-static`).

## 2) المكتبات (بتتنزل أوتوماتيك بأمر واحد)

```bash
npm install
```

المكتبات الموجودة في `package.json`:

| المكتبة | بتعمل إيه |
|---|---|
| `discord.js` | التعامل مع ديسكورد |
| `@discordjs/voice` | الدخول في الرومات الصوتية وتشغيل الصوت |
| `opusscript` / `@discordjs/opus` | ترميز الصوت (opusscript بيشتغل على أي جهاز، وopus الأسرع اختياري) |
| `prism-media` | معالجة الصوت |
| `ffmpeg-static` | FFmpeg جاهز |
| `@napi-rs/canvas` | رسم صور المواقيت والأذكار والتنبيهات |
| `axios` | طلبات الإنترنت (الصوت + المواقيت) |
| `dotenv` | قراءة ملف `.env` |
| `fs-extra` | التعامل مع الملفات |
| `winston` / `chalk` | اللوج الملوّن في الكونسول |

## 3) من Discord Developer Portal

1. بوت جديد + **التوكن**.
2. تفعيل **Message Content Intent** (من تبويب Bot ← Privileged Gateway Intents) — البوت بيستخدمه.
3. الـ **Application ID** (للـ `CLIENT_ID`).

التفاصيل كلها في [دليل التشغيل من الصفر](setup.md).
