## 1) 🧰 تجهيز جهازك

1. نزّل **Node.js** (نسخة 18 أو أحدث، ويفضل LTS) من https://nodejs.org وثبّته.
2. افتح الـ Terminal (أو CMD / PowerShell على ويندوز) واتأكد إنه اتثبت:

```bash
node -v
npm -v
```

لازم يظهرلك أرقام النسخ. لو ظهر خطأ يبقى التثبيت ناقص، اقفل الـ Terminal وافتحه تاني أو أعد التثبيت.

> 📌 المتطلبات كاملة في [requirements.md](requirements.md)

---

## 2) 🤖 إنشاء البوت في ديسكورد

1. ادخل https://discord.com/developers/applications واضغط **New Application**.
2. اكتب اسم البوت (مثلاً: ورتل) واضغط **Create**.
3. من **General Information** انسخ **Application ID** — هتحطه في `CLIENT_ID`.
4. من القايمة اللي على الشمال اختار **Bot**:
   - اضغط **Reset Token** وانسخ التوكن (⚠️ ده سر، متبعتوش لحد ومتحطوش في أي ملف مرفوع على GitHub).
   - انزل لتحت لحد **Privileged Gateway Intents** وفعّل ✅ **Message Content Intent**.
   - اضغط **Save Changes**.

---

## 3) 📥 تحميل المشروع

بـ Git:

```bash
git clone https://github.com/<اسمك>/<اسم-المشروع>.git
cd <اسم-المشروع>
```

أو من زرار **Code ← Download ZIP** على GitHub وفُك الضغط وادخل الفولدر.

بعد كده نزّل المكتبات:

```bash
npm install
```

استنى لحد ما يخلص (ممكن ياخد دقيقة أو اتنين).

---

## 4) 🔑 ضبط ملف .env

انسخ الملف الجاهز:

```bash
# لينكس / ماك
cp .env.example .env

# ويندوز (CMD)
copy .env.example .env
```

افتح `.env` بأي محرر نصوص وعدّل:

```env
BOT_TOKEN=التوكن_اللي_نسخته
CLIENT_ID=الـ_Application_ID
```

باقي السطور اختيارية، وتقدر تسيبها فاضية. اتشرحت جوه الملف نفسه.

> ⚠️ **تنبيه أمان:** ملف `.env` متضاف في `.gitignore` عشان ميترفعش على GitHub بالغلط. متشيلوش من هناك.
> ولو التوكن اتسرّب لأي سبب، ادخل Developer Portal واعمل **Reset Token** فوراً.

## 5) ▶️ تشغيل البوت

```bash
npm start
```

لو كله تمام هتلاقي في الكونسول رسايل زي:

```
✅ Loaded 14 reciter(s)
✅ Loaded 114 surah(s)
Logged in as اسم-البوت#1234
```

وده معناه إن البوت اشتغل وسجّل أوامر السلاش. (تسجيل الأوامر ممكن ياخد لحد ساعة عشان تظهر في كل السيرفرات، لكن غالباً بتظهر في دقايق.)

للإيقاف اضغط `Ctrl + C`.

## 6) ➕ إضافة البوت لسيرفرك

1. افتح الرابط ده بعد ما تحط الـ `CLIENT_ID` بتاعك مكان `YOUR_CLIENT_ID`:

```
https://discord.com/oauth2/authorize?client_id=YOUR_CLIENT_ID&permissions=8&integration_type=0&scope=bot+applications.commands
```

2. اختار السيرفر واضغط **Authorize**.

> 💡 الرابط ده بيدّي البوت صلاحية Administrator للتسهيل. لو عايز تحدّد صلاحيات أقل، البوت محتاج على الأقل: **View Channel، Send Messages، Embed Links، Attach Files، Manage Messages، Connect، Speak** (و **View Audit Log** اختياري).
>
> وبعد ما البوت يشتغل تقدر تكتب `/link-invite` في أي سيرفر وهيبعتلك الرابط جاهز.

---

## 7) ⚙️ إعداد البوت في السيرفر (/setup)

الأمر ده **للأدمن فقط**. اكتب في أي روم:

```
/setup
```

وهتختار الرومات:

| الخيار | معناه |
|---|---|
| `control_channel` | روم **لوحة التحكم** (فيها قايمة الشيوخ والسور وأزرار التخطي والتوقف) |
| `voice_channel` | الروم **الصوتي** اللي البوت هيدخله ويقرا فيه |
| `azkar_channel` | روم **الأذكار** |
| `prayer_channel` | روم **مواقيت الصلاة** والأذان |
| `notice_channel` | روم **التنبيهات** |

بعد الإعداد:

1. البوت هيبعت **لوحة التحكم** في روم `control_channel`.
2. اختار **القارئ** من القايمة.
3. اختار **السورة** — والتلاوة هتشتغل في الروم الصوتي. 🎧
4. حدّد دولتك لمواقيت الصلاة بأمر `/country`.

## 8) ♾️ تشغيل البوت 24 ساعة

لو قفلت الـ Terminal البوت هيقف. عشان يفضل شغال على سيرفر/VPS استخدم **pm2**:

```bash
npm install -g pm2
pm2 start index.js --name wartil
pm2 save
pm2 startup        # نفّذ الأمر اللي هيظهرلك عشان يشتغل مع تشغيل الجهاز
```

أوامر مفيدة:

```bash
pm2 logs wartil       # شوف اللوج
pm2 restart wartil    # إعادة تشغيل (بعد أي تعديل)
pm2 stop wartil       # إيقاف
```

> 🔁 **بعد أي تعديل** في ملفات الشيوخ أو `.env` لازم تعمل **Restart** للبوت.

## 10) 🛠️ المشاكل الشائعة وحلها

| المشكلة | الحل |
|---|---|
| `لم يتم العثور على توكن البوت` | اتأكد إن ملف اسمه `.env` (من غير `.example`) موجود جنب `index.js` وفيه `BOT_TOKEN=...` |
| `Login failed` / `TokenInvalid` | التوكن غلط أو اتعمله Reset. هات توكن جديد |
| `Used disallowed intents` | فعّل **Message Content Intent** من Developer Portal (الخطوة 2) |
| الأوامر مش ظاهرة | استنى شوية بعد أول تشغيل، أو اتأكد إن البوت اتضاف بـ `applications.commands` |
| البوت دخل الروم بس مفيش صوت | اتأكد إن معاه صلاحية **Speak** وإن الروم مش مقفول عليه، وإن جهازك فيه إنترنت |
| خطأ عند `npm install` | حدّث Node.js لنسخة أحدث وجرّب تاني: `npm install` |
| الصوت بيقطع | غالباً ضعف في النت أو ضغط على السيرفر. جرّب سيرفر أقوى |
| رسالة `Missing Access` أو `Missing Permissions` | أدّي البوت صلاحيات الروم المطلوبة |

لو لسه فيه مشكلة افتح **Issue** على GitHub وارفق رسالة الخطأ من الكونسول (**من غير ما تنشر التوكن!**).
